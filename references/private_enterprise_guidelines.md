# Commercial & Private Tech Enterprise (私企/互联网) Resume Guidelines

This guide details specific requirements, review habits, and content formatting principles tailored for Private Enterprises, Internet Tech Companies, and Venture-backed Startups (私营企业、科技独角兽与中大型互联网公司).

---

## 1. Core Differences: State-Owned Enterprise (央国企) vs Private Tech Enterprise (私企)

| Dimension | State-Owned Enterprise (央国企版) | Private Tech Enterprise (私企通用版) |
| :--- | :--- | :--- |
| **Header Focus** | 政治面貌 (共青团员/中共党员)、籍贯、民族、稳定性 | **GitHub 开源主页**、**技术博客/个人主页**、意向全职/实习、现居城市 |
| **Personal Section** | **自我评价 (About Me)**：侧重政治素养、责任心、稳定性、服从组织安排与业务一线调配 | **个人优势 (Highlights)**：侧重 **Owner 闭环交付能力**、**高并发与中间件深潜**、**AI 工程化敏锐度与自驱攻坚** |
| **Skills Section** | 强调工程规范、标准框架覆盖、运维与全栈交付 | 深入 **JUC 多线程与并发锁机制**、**JVM 内存与 GC 调优**、**MySQL 执行计划与索引**、**RabbitMQ 削峰与幂等防重** |
| **Projects Emphasis** | 强调国家项目、社区卫生落地、合规与安全性 | 强调 **QPS 承载、吞吐量提升、时延削减百分比、防刷拦截率与算力优化** |

## 2. Header Optimization for Private Companies

In private tech recruitment, technical screening algorithms and tech leads favor verifiable evidence of coding proficiency:

1. **GitHub Profile & Technical Portfolio**:
   - Prominently include active GitHub handles (e.g., `GitHub: ARTISTA666`) and personal engineering domains (e.g., `siyusong.xyz`).
   - Links demonstrate code transparency, engineering craftsmanship, and personal initiative.
2. **Omit Non-Relevant Institutional Fields**:
   - Safely omit `政治面貌` and `民族`. Private tech companies do not screen candidates on these parameters, and omitting them frees valuable vertical space for technical depth.
3. **Location & Availability**:
   - Retain `现居城市：芜湖市` and clarify graduation / availability timeline (`统招工学硕士 · 2026届`).

## 3. Engineering Narrative: High-Impact Action Verbs & Metrics

- Structure each bullet point with: `【Action / Role】+【Architecture / Technology】+【Quantified Outcome】`.
- Bold high-impact technical keywords for 15-second scanning:
  - **乐观锁版本号控制机制** / **自定义参数化线程池**
  - **Redis + 布隆过滤器拦截无效穿透**
  - **RabbitMQ 异步解耦、削峰填谷与死信队列重试**
  - **稠密向量与 BM25 关键词混合检索** / **RRF 倒数排名融合算法**
  - **流式分片批处理（Pagination Chunking）规避 JVM OOM**
  - **自适应视频流抽帧算法降低算力负载 40%**
